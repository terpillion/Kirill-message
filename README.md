# Предписание к неотложной явке

Готовая вторая версия шуточного сайта-приглашения на Хэллоуин.
HTML, CSS и JavaScript без сборки, внешних библиотек, шрифтов и аналитики.

Сохранены круговой пролёт фотографий, приближение с затемнением,
последовательная смена картинок справа в «Технических ограничениях»,
добавленное фото родственников и крупное фото с мигающими стрелками.
При открытии и перезагрузке страница начинается сверху.
При системной настройке уменьшения движения показывается спокойный вариант.

## Публикация через сайт GitHub

1. Создайте репозиторий, например `halloween-invitation`. Для бесплатного
   GitHub Pages используйте публичный репозиторий.
2. Распакуйте `halloween-github-pages.zip`. В репозитории нажмите
   **Add file → Upload files** и загрузите всё содержимое архива:
   `index.html`, CSS, JavaScript, папку `assets`, `.nojekyll`,
   `.gitignore`, `.gitattributes` и этот README. Сохраните загрузку в `main`.
   Если репозиторий пустой, используйте ссылку **uploading an existing file**.
3. `index.html` должен находиться прямо в корне репозитория, рядом с `assets`.
   Сам ZIP и внешнюю папку `halloween-site` загружать не нужно.
   Если браузер пропустил `.nojekyll`, создайте его через
   **Add file → Create new file**, имя `.nojekyll`, содержимое `Static site`.
4. Откройте **Settings → Pages**. В **Source** выберите
   **Deploy from a branch**, затем **main** и **/(root)**, нажмите **Save**.
5. Дождитесь завершения публикации. Рабочая ссылка появится в разделе Pages.
   Для обычного репозитория адрес будет иметь вид
   `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Все пути относительные: имя репозитория можно выбрать любое.
Сайт также можно разместить в репозитории `ЛОГИН.github.io`.
При следующих обновлениях заменяйте файлы в той же ветке.

Официальная инструкция:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что находится в пакете

- `index.html` — страница;
- `style.css`, `app.js` — оформление, плавная прокрутка и появления;
- `orbit.css`, `orbit.js` — круговой пролёт и приближение;
- `campaign.css`, `campaign.js` — фотография и красные стрелки;
- `technical.css`, `technical.js` — последовательность технических ограничений;
- `assets/` — все необходимые фотографии и изображения;
- `.nojekyll` — публикация готовых статических файлов;
- `.gitattributes`, `.gitignore` — настройки текстовых файлов и исключений.

## Локальный просмотр

Из папки сайта запустите `python -m http.server 4187 --bind 127.0.0.1`
и откройте http://127.0.0.1:4187/ . Python нужен только для локального
просмотра, на GitHub его устанавливать не требуется.

Проверка после публикации: страница открывается сверху, все изображения
загружаются, анимации работают при прокрутке вперёд и назад.
Файлы проверок, скриншоты, исходный PDF, старые версии и туннель
в этот релиз не входят. Пакет подготовлен локально; публикация
в репозиторий выполняется отдельно.
